# Map sources and status by state

Draft. Status checked on 2026-10-03.

The table lists, for each state with more than one House seat, the congressional map that governs the general election of November 3, 2026, whether it differs from the map used in November 2024, and its legal status. Each map name links to the official source.

Status values:

- Enacted: in effect, no pending challenge found.
- Challenged: in effect, litigation pending.
- Blocked: adopted, but a court or a referendum keeps it from being used.

Rows marked with * have no state-specific source dated 2026. Their status rests on the Census 120th Congress block equivalency file (2026-08-31), which lists the states with new maps, and on national trackers from late September 2026.

The CD120 file contains Missouri's 2025 map (HB 1), which is not used in November 2026. The Census Bureau notes this on its [congressional districts page](https://www.census.gov/programs-surveys/decennial-census/about/rdo/congressional-districts.html).

State block files for TX, CA and NC match CD120 block by block. Florida matched on all rows checked. Louisiana's state file contains 1,751 GEOIDs that are not 2020 tabulation blocks, so CD120 is the better source there.

## Maps that changed between 2022 and 2024

The ALARM simulations use the maps of the 2022 election as their reference plan. Five states redrew between the 2022 and 2024 elections: Alabama, Georgia, Louisiana, New York and North Carolina (Census 119th Congress page). Compared with 2022, the 2026 map differs in eleven states: AL, CA, FL, GA, LA, NC, NY, OH, TN, TX and UT.
