# Herontwerp van de site: implementatieplan (fase 7)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** De site uit het herontwerp: een kopband met metastrook, hoofdstuk 01 met drie rijen en een wafel van 429 zetels, hoofdstuk 02 met kaart, grootste effecten en staatsblad, hoofdstuk 03 met de blokken over meerderheid, Senaat, concurrerende districten, hertekeningen en controle, en hoofdstuk 04 met de ingeklapte methode, gevoed door dezelfde `site/data/results.json` en `site/data/map.topojson`.

**Architecture:** Dezelfde opbouw als fase 6: één pagina zonder bouwstap, pure modules die van `results.json` teksten en geometrie maken (getest met `node --test`), en DOM-modules die alleen tekenen. De pagina wordt hoofdstuk voor hoofdstuk omgebouwd. Na elke taak werkt de site en slagen `npm test` en `node tools/check_site.mjs`, omdat elke taak die de pagina verandert de controles van dat deel in dezelfde commit bijwerkt.

**Tech Stack:** Node 24 (`node --test`, ingebouwde `WebSocket`), d3 7.9.0 en topojson-client 3.1.0 uit `site/vendor/`, Edge of Chrome voor de headless controle, Python 3.12 uit `.venv` alleen voor `make serve`.

## Volgorde: de site werkt na elke commit

Waarom deze volgorde:

1. **Eerst de tokens (7.1).** Het mockup gebruikt andere namen (`--paper`, `--ink` voor tekst, `--accent`). Het plan houdt de namen van de site en geeft ze de waarden van het mockup. Daardoor verandert er in 7.1 alleen kleur, geen code, en draait de huidige site met het nieuwe palet. De headless controle verandert op één regel: de achtergrondkleur in de donkere modus.
2. **Dan alle pure functies (7.2 tot en met 7.5).** Die raken de pagina niet, dus de site blijft zoals hij is, en elke DOM-taak daarna kan op geteste weergavemodellen bouwen.
3. **Dan de pagina van boven naar beneden (7.6 tot en met 7.10).** Elke taak vervangt één aaneengesloten deel en past in dezelfde commit de controlegroepen van dat deel aan. Element-id's die controles en `main.js` gebruiken, blijven waar het kan bestaan (`map`, `pick`, `sheet`, `sheet-title`, `majority-text`, `redraw-list`, `by-control`, `method` en de rest uit de tabel hieronder), zodat de groepen van fase 6 grotendeels blijven werken.
4. **Hoofdstuk 03 vóór 04.** Taak 7.9 haalt de landelijke strook weg, met de klokvormige zetelas. Taak 7.10 zet die as terug als figuur in de methode. Tussen die twee commits ontbreekt de figuur; niets is kapot, er wijst geen link naar.
5. **Toegankelijkheid en eindcontrole als laatste (7.11, 7.12).** Elke DOM-taak houdt de bestaande toetsenbord- en indelingscontroles groen; 7.11 voegt de controles van hoofdstuk 8 van het herontwerp toe en zet de groep `layout` om naar de nieuwe indeling.

Een taak die halverwege vastloopt, laat geen halve pagina achter: commit pas als `npm test` en de hele headless controle slagen.

## Keuzes in dit plan

1. **Open punten van het herontwerp.** Het plan volgt bij alle negen de aanbeveling: labels uit CLAUDE.md, "Geographic effect" en "Drawing effect" overal, de landelijke zetelas als figuur in de methode, de zetelstrook in het blad, de lijst als blad zonder gekozen staat, de zes staten met één zetel kiesbaar, de knop voor neutrale kleuren blijft, een kolom van maximaal 83rem, "Geodienst, University of Groningen". De taak die een ander besluit raakt, staat bij elk punt in het herontwerp.
2. **Tokennamen.** Zie hoofdstuk 7 van het herontwerp: de namen van de site blijven, de waarden komen uit het mockup; nieuw zijn `--tint`, `--mast`, `--mast-fg` en `--mast-muted`. In de CSS uit het mockup is `var(--paper)` dus `var(--bg)`, `var(--ink)` is `var(--fg)`, `var(--accent)` is `var(--ink)`, `var(--band)` is `var(--mast)`, `var(--d)` en `var(--r)` zijn `var(--party-d)` en `var(--party-r)`, en `--font-display` is `--font-head`.
3. **Klassenamen.** Een paar klassen uit het mockup bestaan al op de site met een andere betekenis. Het plan hernoemt de nieuwe: de rijen van 01 heten `.choice` (niet `.row`, dat zijn de rijen van de lijst), de metastrook `.metastrip` (niet `.meta`), het effectenblok `.effectlist` (niet `.effects`), de stippenrijen `svg.dotrows` (niet `.axis`, dat is de as van d3).
4. **Stippenrijen in plaats van markeringen boven de as.** Het mockup tekent de stemas van de meerderheid, de concurrerende districten en de strook in het blad als rijen met een stip per uitkomst. Eén functie `drawDotRows` in `charts.js` tekent ze alle drie. De concurrerende districten krijgen twee rijen (Neutral baseline met band, Enacted) in plaats van twee stippen op één rij, zodat elke stip een label heeft.
5. **Wafel op maat.** De wafel heeft een viewBox van 394 bij 170 eenheden (33 kolommen van 12) en is hoogstens 42rem breed. De getallen erboven zijn 12 eenheden; op 375 pixels is de wafel 343 pixels breed, dus 10,4 pixels op het scherm. Daarmee haalt hij de bestaande controle "chart text is at least 10px".
6. **Opruimen.** Functies waarvan het blok vervalt, gaan in dezelfde taak weg met hun tests: `explainerView` en `nationalView().keyline` (7.6), `drawVoteAxis`, `VOTE_AXIS`, `voteDomain` en `voteTicks` (7.9), `national.js` (7.9). De rest van de pure modules en hun tests blijft.
7. **Aantallen controles.** Het plan noemt het totaal aantal headless controles alleen voor de eindstand (zie Proefrun). Elke taak verwacht `0 failed`.

```js
// --- The waffle of chapter 01 (Task 7.2) ---------------------------------------------------------

export const WAFFLE = { rows: 13, step: 12, size: 10, top: 16, edge: 12 }; // top: room for the tick and its number

/** Columns, width and height in viewBox units of a waffle of `total` seats, filled column by column. */
export function waffleSize(total, w = WAFFLE) {
  const columns = Math.ceil(total / w.rows);
  return { columns, width: columns * w.step - (w.step - w.size), height: w.top + w.rows * w.step - (w.step - w.size) };
}

/** Top left corner of seat `i` (from 0): down a column of 13, then the next column. */
export function waffleCell(i, w = WAFFLE) {
  return { x: Math.floor(i / w.rows) * w.step, y: w.top + (i % w.rows) * w.step };
}

/** x of the number above seat `n` (from 1), the last Democratic seat; at least 12 units from either edge. */
export function waffleTick(n, total, w = WAFFLE) {
  const { width } = waffleSize(total, w);
  const x = waffleCell(Math.max(n, 1) - 1, w).x + w.size / 2;
  return Math.min(Math.max(x, w.edge), width - w.edge);
}

/** Cells of seats lo to hi (from 1, both included): the outline of the neutral band. */
export function waffleBand(lo, hi, w = WAFFLE) {
  return Array.from({ length: Math.max(0, hi - lo + 1) }, (_, k) => waffleCell(lo - 1 + k, w));
}

// --- Rows of dots: the strip in the state record and the axes of chapter 03 (Task 7.2) ----------

export const DOT_ROWS = { left: 112, right: 16, row: 26, top: 24, bottom: 22 }; // left: room for "Neutral baseline"

/** Ticks from 0 to `total` seats: the smallest step of 1, 2, 5, 10, 20, 50 or 100 that gives at most `most` ticks. */
export function seatTicks(total, most = 7) {
  const step = [1, 2, 5, 10, 20, 50, 100].find((s) => Math.floor(total / s) + 1 <= most) ?? 100;
  return Array.from({ length: Math.floor(total / step) + 1 }, (_, k) => k * step);
}

/**
 * Domain on whole steps around the values, with at least `pad` to spare on each side, and a tick per step.
 * The small epsilon keeps a value that is a whole step in floating point (0.49 / 0.01) on that step.
 */
export function rowDomain(values, step, pad = step / 2) {
  const low = Math.floor((Math.min(...values) - pad) / step + 1e-9);
  const high = Math.ceil((Math.max(...values) + pad) / step - 1e-9);
  const at = (k) => Number((k * step).toFixed(10));
  return { domain: [at(low), at(high)], ticks: Array.from({ length: high - low + 1 }, (_, i) => at(low + i)) };
}

/**
 * Side of a value text next to its dot: 'end' (left of the dot) when the dashed base line lies within `gap`
 * units to the right, so the text would run over it, or when the dot is near the right edge; else 'start'.
 */
export function rowTextAnchor(x, baseX, width, gap = 40, edge = 60) {
  if (x > width - edge) return 'end';
  if (baseX !== null && x <= baseX && x > baseX - gap) return 'end';
  return 'start';
}
```

```js
// Texts and view models for the four chapters of the redesign (docs/superpowers/specs/2026-10-08-redesign-design.md).
// Pure, like model.js and extensions.js: no DOM and no d3, every number through format.js, nothing new computed.
import { seats, count, effect, effectWords } from './format.js';
import { nationalView } from './model.js';

export const LABELS = { proportional: 'Proportional', neutral: 'Neutral baseline', enacted: 'Enacted' };
export const EFFECT_LABELS = { geographic: 'Geographic effect', drawing: 'Drawing effect' };

const sum = (values) => values.reduce((a, b) => a + b, 0);
// "217 to 229", or one number if both ends are equal
const range = (lo, hi) => (lo === hi ? seats(lo) : `${seats(lo)} to ${seats(hi)}`);

// --- Chapter 01: one electorate, three outcomes (Task 7.3) --------------------------------------

/** Everything chapter 01 shows: the three rows, the effects between them, the band and the sentences beside the waffle. */
export function outcomesView(results) {
  const n = results.national;
  const national = nationalView(results);
  const states = count(Object.keys(results.states).length);
  const plans = count(sum(Object.values(results.states)[0].neutral.dist));
  const { median, p5, p95 } = n.neutral;
  const band = p5 === p95 ? `90% of outcomes give ${seats(p5)}` : `90% of outcomes: ${seats(p5)} to ${seats(p95)}`;
  const where = n.enacted < p5 ? 'below that range' : n.enacted > p95 ? 'above that range' : 'within that range';
  const step = (key, value, from, to) => ({
    key, label: EFFECT_LABELS[key], value: effect(value), words: effectWords(value),
    detail: `${effectWords(value)} (${seats(from)} to ${seats(to)})`,
  });
  return {
    intro: `Democratic seats in the ${states} states with more than one seat, counted three ways with the same votes. `
      + 'Select a row to see it as seats.',
    total: n.seats,
    rows: [
      { key: 'proportional', label: LABELS.proportional, seats: n.proportional, value: seats(n.proportional),
        desc: "Each state's seats in proportion to its two-party vote." },
      { key: 'neutral', label: LABELS.neutral, seats: median, value: seats(median),
        desc: `The middle outcome of the neutral maps. ${band}.` },
      { key: 'enacted', label: LABELS.enacted, seats: n.enacted, value: seats(n.enacted),
        desc: 'The maps used on November 3, 2026.' },
    ],
    steps: [
      step('geographic', n.effects.geographic, n.proportional, median),
      step('drawing', n.effects.drawing, median, n.enacted),
    ],
    band: {
      lo: p5, hi: p95,
      key: `Outlined: ${p5 === p95 ? 'seat' : 'seats'} ${range(p5, p95)}, where the Democratic seats end in 90% of neutral outcomes`,
    },
    effectsNote: 'The geographic effect is the difference between proportional seats and neutral maps. '
      + 'The drawing effect is the difference between neutral maps and the enacted maps.',
    spread: `90% of neutral outcomes give Democrats ${range(p5, p95)} seats. The enacted maps give ${seats(n.enacted)}, ${where}.`,
    position: national.position,
    neutralNote: `The neutral maps come from the ALARM Project. For each state a computer drew ${plans} maps that follow `
      + "the state's rules, such as equal population and the Voting Rights Act, without using party data. "
      + `The national figures combine the ${states} states.`,
    scope: national.note,
  };
}

/** The line above the waffle and its title, for the chosen row. */
export function waffleText(view, key) {
  const row = view.rows.find((r) => r.key === key);
  const rest = view.total - row.seats;
  return {
    d: seats(row.seats),
    r: seats(rest),
    label: `${row.label}: ${seats(row.seats)} Democratic and ${seats(rest)} Republican seats of ${seats(view.total)}.`,
  };
}
```

```js
/**
 * The state in a location hash, or "" for the whole map.
 * "#TX", "#tx" and "#%54X" give "TX"; an unknown code, "#method" or a broken escape give "".
 * A single-seat state gives its code only when the caller passes the six as `single` (redesign, open point 6).
 * @param {string} hash location.hash
 * @param {object} states results.json "states", keyed by postal code
 * @param {object} [single] the single-seat states, keyed by postal code
 * @returns {string}
 */
export function stateFromHash(hash, states, single = {}) {
  let code;
  try {
    code = decodeURIComponent(String(hash ?? '').replace(/^#/, '')).trim().toUpperCase();
  } catch {
    return '';
  }
  return /^[A-Z]{2}$/.test(code) && (Object.hasOwn(states, code) || Object.hasOwn(single, code)) ? code : '';
}
```

```js
// --- Chapter 02: state by state (Task 7.4) ------------------------------------------------------

export const LARGEST_MIN = 3; // seats; every state at or above it is listed, the rest is counted

/**
 * "Drawing effects of 3 seats or more": every state at or above the threshold, by size, toward Republicans
 * first at equal size, then by name; and one sentence that counts the states below it.
 */
export function largestEffects(results, min = LARGEST_MIN) {
  const rows = Object.entries(results.states).map(([postal, s]) => ({ postal, name: s.name, drawing: s.effects.drawing }));
  const chips = rows
    .filter((r) => Math.abs(r.drawing) >= min)
    .sort((a, b) => Math.abs(b.drawing) - Math.abs(a.drawing) || a.drawing - b.drawing || a.name.localeCompare(b.name, 'en'))
    .map((r) => ({ ...r, label: effect(r.drawing), aria: `${r.name}, ${effectLine(r.drawing)}` }));
  const small = rows.filter((r) => r.drawing !== 0 && Math.abs(r.drawing) < min).length;
  const zero = rows.filter((r) => r.drawing === 0).length;
  const under = min === 2 ? '1 seat' : min === 3 ? '1 or 2 seats' : `1 to ${count(min - 1)} seats`;
  const parts = [];
  if (small > 0) parts.push(`${count(small)} ${plural(small, 'state', 'states')} at ${under} either way`);
  if (zero > 0) parts.push(`${count(zero)} ${plural(zero, 'state', 'states')} at 0`);
  return {
    title: `Drawing effects of ${count(min)} seats or more`,
    chips,
    rest: parts.length > 0 ? `Then ${parts.join(', and ')}.` : '',
  };
}

/** The state record: the sheet of Phase 6 (stateSheet, stateExtras) with the headline and the seat strip. */
export function recordView(results, postal) {
  const s = results.states[postal];
  const sheet = stateSheet(results, postal);
  const d = s.effects.drawing;
  const words = effectWords(d);
  return {
    ...sheet,
    kicker: 'State record',
    extras: stateExtras(results, postal),
    headline: {
      value: effect(d),
      drawing: d,
      sentence: d === 0
        ? 'No difference from the neutral baseline.'
        : `${words[0].toUpperCase()}${words.slice(1)} compared with the neutral baseline.`,
    },
    strip: {
      domain: [0, s.seats],
      ticks: seatTicks(s.seats).map((value) => ({ value, text: seats(value) })),
      rows: [
        { key: 'proportional', label: LABELS.proportional, value: s.proportional },
        { key: 'neutral', label: LABELS.neutral, value: s.neutral.median, band: [s.neutral.p5, s.neutral.p95] },
        { key: 'enacted', label: LABELS.enacted, value: s.enacted, filled: true },
      ],
      label: axisLabel(s.name, sheet.axis, 'maps'),
    },
  };
}

/** The short record of a state with one seat (redesign, chapter 4). */
export function singleSeatView(results, postal) {
  const s = results.national.single_seat.find((x) => x.postal === postal);
  return {
    postal,
    name: s.name,
    kicker: 'State record',
    headline: '1 seat',
    lines: [AT_LARGE_TEXT, `Not counted in the ${seats(results.national.seats)} seats compared here.`],
  };
}
```

```js
/** A spec for drawDotRows: the domain on whole steps around the values, ticks with their text, and the rows. */
function dots(values, step, tickText, rows, base = undefined) {
  const { domain, ticks } = rowDomain(values, step);
  return { domain, ticks: ticks.map((value) => ({ value, text: tickText(value) })), rows, ...(base ? { base } : {}) };
}
```

Maak `site/js/outcomes.js`:

```js
// Chapter 01, "One electorate. Three outcomes." (redesign, chapter 3): three rows as a radio group with the two
// effects between them, a waffle of the seats that follows the chosen row, and the sentences beside it.
// Texts come from chapters.js and geometry from axes.js; this module only draws.
import { WAFFLE, waffleSize, waffleCell, waffleTick, waffleBand } from './axes.js';
import { waffleText } from './chapters.js';

const SVG_NS = 'http://www.w3.org/2000/svg';
const $ = (id) => document.getElementById(id);

function node(tag, attrs = {}, text = null, ns = null) {
  const el = ns ? document.createElementNS(ns, tag) : document.createElement(tag);
  for (const [name, value] of Object.entries(attrs)) el.setAttribute(name, value);
  if (text !== null) el.textContent = text;
  return el;
}
const svgNode = (tag, attrs, text = null) => node(tag, attrs, text, SVG_NS);

/**
 * Draw chapter 01. Nothing is colored until the first paint(colors).
 * @param {object} view outcomesView(results)
 * @param {{reduceMotion: () => boolean}} o
 * @returns {{paint(colors: object): void, select(key: string, animate?: boolean): void}}
 */
export function renderOutcomes(view, { reduceMotion }) {
  $('outcomes-intro').textContent = view.intro;

  // The rows: one tab stop; arrows and Home/End move the choice and the focus (redesign, chapter 8).
  const group = $('scen');
  group.replaceChildren();
  const rows = view.rows.map((row, i) => {
    const button = node('button', { type: 'button', class: 'choice', role: 'radio', 'aria-checked': 'false', tabindex: '-1', 'data-key': row.key });
    button.append(node('span', { class: 'dot', 'aria-hidden': 'true' }), node('span', { class: 'lab' }, row.label),
      node('span', { class: 'big' }, row.value), node('span', { class: 'desc' }, row.desc));
    button.addEventListener('click', () => select(row.key, true));
    button.addEventListener('keydown', (event) => {
      const last = view.rows.length - 1;
      const to = { ArrowDown: i + 1, ArrowRight: i + 1, ArrowUp: i - 1, ArrowLeft: i - 1, Home: 0, End: last }[event.key];
      if (to === undefined) return;
      event.preventDefault();
      const next = view.rows[(to + view.rows.length) % view.rows.length].key;
      select(next, true);
      group.querySelector(`[data-key="${next}"]`).focus();
    });
    group.append(button);
    const step = view.steps[i];
    if (step) {
      const line = node('div', { class: 'step' });
      const text = node('span');
      text.append(`${step.label} `, node('b', {}, step.value), `: ${step.words}`);
      line.append(text);
      group.append(line);
    }
    return button;
  });

  // The waffle: one square per seat, column by column; the band outline; the number above the last Democratic seat.
  const size = waffleSize(view.total);
  const svg = $('waffle');
  svg.setAttribute('viewBox', `0 0 ${size.width} ${size.height}`);
  for (const g of svg.querySelectorAll('g')) g.remove();
  const seatLayer = svgNode('g');
  const squares = Array.from({ length: view.total }, (_, i) => {
    const { x, y } = waffleCell(i);
    const rect = svgNode('rect', { class: 'seat', x, y, width: WAFFLE.size, height: WAFFLE.size });
    seatLayer.append(rect);
    return rect;
  });
  const band = svgNode('g', { class: 'band', display: 'none' });
  for (const { x, y } of waffleBand(view.band.lo, view.band.hi)) {
    band.append(svgNode('rect', { x: x + 0.7, y: y + 0.7, width: WAFFLE.size - 1.4, height: WAFFLE.size - 1.4 }));
  }
  const tick = svgNode('g', { class: 'tick', 'aria-hidden': 'true' });
  svg.append(seatLayer, band, tick);
  $('key-band-text').textContent = view.band.key;

  // The two columns under rows and waffle.
  const effect = (step) => {
    const line = node('div', { class: 'eff' });
    line.append(node('span', { class: 'k' }, step.label), node('span', { class: 'v' }, step.value), node('span', { class: 'w' }, step.detail));
    return line;
  };
  $('effects').replaceChildren(...view.steps.map(effect), node('p', { class: 'note' }, view.effectsNote));
  $('spread').replaceChildren(node('p', {}, view.spread), node('p', {}, view.position),
    node('p', { class: 'note' }, view.neutralNote), node('p', { class: 'note' }, view.scope));

  let current = 'enacted';
  let shown = null; // the Democratic count on screen, where a change starts from
  let colors = null;

  function draw(animate) {
    if (!colors) return;
    const row = view.rows.find((r) => r.key === current);
    const n = row.seats;
    const motion = animate && shown !== null && !reduceMotion();
    squares.forEach((rect, i) => {
      const fill = colors.party(i < n);
      if (rect.getAttribute('fill') === fill) return;
      // squares change one after another, starting at the old count
      rect.style.transitionDelay = motion ? `${Math.abs(i - shown) * 18}ms` : '0ms';
      rect.style.transitionDuration = motion ? '' : '0s';
      rect.setAttribute('fill', fill);
    });
    shown = n;
    band.setAttribute('display', current === 'neutral' ? 'inline' : 'none');
    $('key-band').hidden = current !== 'neutral';
    const mid = waffleCell(Math.max(n, 1) - 1).x + WAFFLE.size / 2;
    tick.replaceChildren(
      svgNode('line', { x1: mid, x2: mid, y1: WAFFLE.top - 4, y2: WAFFLE.top - 1 }),
      svgNode('text', { x: waffleTick(n, view.total), y: WAFFLE.top - 6, 'text-anchor': 'middle' }, row.value),
    );
    const text = waffleText(view, current);
    const who = (name, value, toD) => {
      const span = node('span', { class: 'who' });
      const swatch = node('i', { class: 'sw', 'aria-hidden': 'true' });
      swatch.style.background = colors.party(toD);
      span.append(swatch, name, node('b', {}, value));
      return span;
    };
    $('readout').replaceChildren(who('Democrats', text.d, true), who('Republicans', text.r, false));
    $('waffle-label').textContent = text.label;
  }

  function select(key, animate = false) {
    current = key;
    for (const button of rows) {
      const on = button.dataset.key === key;
      button.setAttribute('aria-checked', String(on));
      button.tabIndex = on ? 0 : -1;
    }
    draw(animate);
  }

  select(current);
  return {
    /** Colors for the squares and the key; again after a palette or theme change. */
    paint(next) {
      colors = next;
      for (const swatch of document.querySelectorAll('#outcomes .wkey .sw')) swatch.style.background = colors.party(swatch.classList.contains('d'));
      draw(false);
    },
    select,
  };
}
```

```js
/**
 * "Drawing effects of 3 seats or more" above the map (redesign, chapter 4): a button per state and the
 * sentence for the rest. Drawn once, so a button keeps the focus; the returned function marks the chosen
 * state and colors the swatches.
 * @param {object} view largestEffects(results)
 * @returns {(colors: object, selected: string) => void}
 */
export function renderLargest(el, view, onSelect) {
  const root = d3.select(el).html('');
  root.append('span').attr('class', 'k').text(view.title);
  const buttons = view.chips.map((chip) => {
    const button = root.append('button').attr('type', 'button').attr('class', 'chip').attr('data-postal', chip.postal)
      .attr('aria-label', chip.aria).on('click', () => onSelect(chip.postal));
    button.append('i').attr('class', 'sw').attr('aria-hidden', 'true');
    button.append('span').text(chip.postal);
    button.append('b').text(chip.label);
    return { button, chip };
  });
  if (view.rest) root.append('span').attr('class', 'rest').text(view.rest);
  return (colors, selected) => {
    for (const { button, chip } of buttons) {
      button.attr('aria-current', chip.postal === selected ? 'true' : null);
      button.select('.sw').style('background', colors.effect(chip.drawing));
    }
  };
}
```

```js
/**
 * Rows of dots on one axis (redesign, chapters 4 and 5): a label per row, the band where a row has one,
 * an open dot or a filled one (Enacted), an optional value text beside the dot, and an optional dashed
 * base line with its label (the actual vote on the House majority axis).
 * @param {Element} el
 * @param {{domain: number[], ticks: {value: number, text: string}[], rows: object[], base?: {value: number, text: string}}} spec
 * @param {string} label text alternative
 * @param {number} maxUnits widest chart in viewBox units
 */
export function drawDotRows(el, spec, label, maxUnits = 560) {
  const m = DOT_ROWS;
  const top = spec.base ? m.top : 6;
  const bottom = top + m.row * spec.rows.length;
  const { svg, width: W } = chartSvg(el, maxUnits, bottom + m.bottom, label);
  svg.classed('dotrows', true);
  const x = d3.scaleLinear().domain(spec.domain).range([m.left, W - m.right]);
  for (const tick of spec.ticks) {
    svg.append('line').attr('class', 'grid').attr('x1', x(tick.value)).attr('x2', x(tick.value)).attr('y1', top).attr('y2', bottom);
    svg.append('text').attr('x', x(tick.value)).attr('y', bottom + 15).attr('text-anchor', 'middle').text(tick.text);
  }
  const baseX = spec.base ? x(spec.base.value) : null;
  spec.rows.forEach((row, i) => {
    const cy = top + m.row * i + m.row / 2;
    svg.append('text').attr('class', 'lbl').attr('x', 0).attr('y', cy + 4).text(row.label);
    if (row.band && row.band[1] > row.band[0]) {
      svg.append('rect').attr('class', 'bandr').attr('x', x(row.band[0])).attr('y', cy - 6)
        .attr('width', x(row.band[1]) - x(row.band[0])).attr('height', 12);
    }
    svg.append('circle').attr('class', row.filled ? 'mk filled' : 'mk').attr('cx', x(row.value)).attr('cy', cy).attr('r', 5);
    if (row.text) {
```
